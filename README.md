## 🇬🇧 English

> **Course:** React · Week 3 assignment

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> About the Project
**React Mastery** is a web platform for learning the React ecosystem from scratch to advanced level through interactive lessons, a live code editor and real-world examples. The lesson content is in Turkish.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Key Features
* 📚 **20 lessons in 3 tracks:** Core Concepts (8), Hooks (6) and Advanced (6).
* 💻 **Live playground:** Each lesson has a code example, a hands-on task and its expected output.
* ❓ **Quizzes:** Multiple-choice questions at the end of every lesson.
* 👤 **Profile & progress:** Sign-up/login pages and a profile page; progress is kept in the browser (`localStorage`).
* 🏅 **Certificate:** A completion certificate page once the course is finished.
* 🌗 **Light/dark theme** and smooth page transitions with Framer Motion.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Tech Stack
React · TypeScript · Vite · React Router · Tailwind CSS · Radix UI (shadcn/ui) · Framer Motion

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Running
```bash
npm install
npm run dev
```
Then open the address Vite prints (usually `http://localhost:5173`).

## 🇹🇷 Türkçe

> **Ders:** React · 3. hafta ödevi

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Memo.png" width="26" align="center"> Proje Hakkında
**React Mastery**, React ekosistemini etkileşimli dersler, canlı kod editörü ve gerçek dünya örnekleriyle sıfırdan zirveye öğrenmek için hazırlanmış bir web platformudur.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Glowing%20Star.png" width="26" align="center"> Temel Özellikler
* 📚 **3 bölümde 20 ders:** Temel Kavramlar (8), Hook'lar (6) ve İleri Seviye (6).
* 💻 **Canlı kod alanı:** Her derste kod örneği, uygulamalı görev ve beklenen çıktı.
* ❓ **Quizler:** Her dersin sonunda çoktan seçmeli sorular.
* 👤 **Profil ve ilerleme:** Kayıt/giriş ve profil sayfaları; ilerleme tarayıcıda (`localStorage`) saklanır.
* 🏅 **Sertifika:** Kurs tamamlandığında bitirme sertifikası sayfası.
* 🌗 **Açık/koyu tema** ve Framer Motion ile akıcı sayfa geçişleri.

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Hammer%20and%20Wrench.png" width="26" align="center"> Teknoloji Yığını
React · TypeScript · Vite · React Router · Tailwind CSS · Radix UI (shadcn/ui) · Framer Motion

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="26" align="center"> Çalıştırma

